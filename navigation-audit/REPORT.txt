DESIGN AND BEHAVIOR
Desktop/laptop navigation remains horizontal, one row, with the existing dropdown appearance wherever the measured navigation fits. Fine-pointer 1366px, 1440px and 1920px tests retain the full row. At 1280px it falls back to MENU because the existing full navigation is too tight; labels are not shrunk or wrapped to force a fit.
Compact navigation applies below 1280px, on primary-coarse-pointer/no-hover tablets through 1366px, or when the desktop row would collide with the branding. This includes the tested iPad Pro landscape while preserving horizontal navigation on a similarly sized fine-pointer laptop.
Tablets: spacious two-column ivory panel with sage typography and rules, positioned below the existing header. Each column has its own stack of categories. Panel height follows its content up to the available viewport height. Phones at 600px and below: one column, including submenus.
All original categories and 68 link instances are retained, in order, with original labels/URLs. Nodes are moved into temporary column wrappers, never cloned; the original direct-child layout is restored in desktop mode. Expandable categories use touch-friendly accordion controls and plus/minus indicators. Only one category expands at a time. The existing Life Changes overview link remains inside its submenu.
Primary targets are at least 56px high; submenu links at least 44px. Long Buyers/city submenus scroll inside the bounded panel. The page behind it stays stationary. Close remains in the header, with Escape and backdrop dismissal also available. Keyboard focus cycles within the menu and returns to MENU on dismissal. Background main/footer content is temporarily inert and restored on close. Orientation changes close/reset the menu cleanly.
The scroll-lock helper preserves the prior inline overflow value and priority, and defeats the legacy !important overflow rule only while the menu is open. Chat remains usable after navigation.
No logo artwork, contact details, page copy, card styling, city sections, homepage video, metadata, or link destinations were edited.
