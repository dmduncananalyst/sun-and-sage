OPENING / PUBLISHING
1. Extract the ZIP completely.
2. Open index.html for a local preview. For a complete browser audit or normal hosting, serve the extracted folder with a static web server.
3. Publish the extracted site files, keeping the folders intact. index.html and assets/ belong together at the publishing root.
4. For GitHub Pages, the entry file must be at the top level of the configured publishing folder or deployment artifact. The ZIP itself is a transport package, not the entry page.
